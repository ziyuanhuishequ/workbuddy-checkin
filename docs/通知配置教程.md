# 结果通知配置教程

签到完成后，把结果推送到你的手机/群里。**配好了每天自动签到就不用管了，出错会主动找你。**

> 通知是「尽力而为」的：推送失败**不影响签到本身**，只会在日志里记一笔。

---

## ⚠️ 先分清：有两套通知，互不干扰

| | **管理员通知** | **用户通知** |
|---|---|---|
| 在哪配 | 控制台「设置」→「结果通知」 | 用户自己在 `/me` 的「微信提醒」里配 |
| 谁收 | **你** | **每个用户自己** |
| 收到什么 | 全部账号的汇总结果 | 只推**他自己那一个账号**的通知：登录完成（含积分明细）、每日签到结果、凭据失效提醒 |
| 支持哪些渠道 | 企业微信 / 钉钉 / 飞书 / Server 酱 / 自定义 | **只能 Server 酱**（因为要推个人微信） |

- 用户在 `/join` 添加成功后，页面会**直接提示他去开提醒**，并给出 3 步教程。
- 用户开了之后会收到三类消息：
  1. **登录完成**（每次登录都发）：今日积分、本次签到拿到多少、明天预计多少；
  2. **每天签到完**：同样的积分三行 + 签到结论；
  3. **凭据失效**：签到停了，以及**去哪儿重新登录 + 联系站长 `www.example.com`**。
- 签到/失效这两类话题**每天最多推一条**，重试不会反复轰炸他；登录通知按「每次登录」发，同账号 90 秒内只发一条（防止登录重试连发）。
- 用户随时可以在 `/me` 里「关闭提醒」。

**下面这部分讲的是「管理员通知」。** 用户通知不需要你配置，他们自己会开。

---

## 先选一种

| 方式 | 推到哪 | 难度 | 适合谁 |
|---|---|---|---|
| **Server 酱** | **个人微信** | ⭐ 最简单 | **推荐给大部分人**，不用建群、不用企业微信 |
| 企业微信群机器人 | 企业微信群 | ⭐⭐ | 公司用企业微信 |
| 钉钉群机器人 | 钉钉群 | ⭐⭐ | 公司用钉钉（**有个关键词的坑，见下**） |
| 飞书群机器人 | 飞书群 | ⭐⭐ | 公司用飞书 |
| 自定义 Webhook | 任意支持的服务 | ⭐⭐⭐ | 自己写脚本接 |

**结论**：如果你只是想让**自己微信**收到提醒 → 选 **Server 酱**，3 分钟搞定。

---

## 推送时机怎么选

| 选项 | 效果 | 建议 |
|---|---|---|
| **仅失败时** | 只在有账号签到失败 / 凭据失效时推一条 | ✅ **推荐**，平时不打扰，出事才响 |
| 每次都推 | 每天签完都推一条（成功几个、失败几个） | 想每天确认一次就选这个 |
| 从不推送 | 不推 | 只挂 webhook 但暂时不想收 |

配好之后点「**发送测试通知**」，手机上能收到就说明通了。

## 一、Server 酱（推个人微信，推荐）

### 1. 注册拿 SendKey

1. 浏览器打开 **<https://sct.ftqq.com/>**
2. 点**微信扫码登录**（用你自己的微信扫）
3. 登录后进入「**SendKey**」页面
4. 复制那串 **SendKey**，形如：

   ```
   SCT123456Txxxxxxxxxxxxxxxxxxxxxxxx
   ```

### 2. 填到控制台

宝塔后台 → `https://你的域名` → 登录 → 「**设置**」页 → 「**结果通知**」：

| 字段 | 填什么 |
|---|---|
| 通知方式 | **Server 酱（推微信）** |
| 推送时机 | 仅失败时（推荐） |
| Webhook 地址 / SendKey | 粘上面那串 SendKey（**只填 SendKey 就行**） |

### 3. 关注公众号才能收到

微信里搜索并关注「**Server酱**」服务号。**不关注收不到消息。**

### 4. 测试

点「**发送测试通知**」。手机微信应该立刻收到一条。

> ⚠️ Server 酱免费版**每天有推送条数限制**（一般 5 条）。日常只签到是 1 条；
> 如果每次登录也要通知，一天大概 2 条，仍然够用。真的超了就在 `/me` 里关掉提醒，或换 Server 酱的付费版。

## 二、企业微信群机器人

> 需要**企业微信**（不是个人微信）。公司有企业微信的话最方便。

### 1. 建群 + 加机器人

1. 打开**企业微信**（电脑版）
2. 随便建一个群，或者用现有的群（可以建个只有自己的群）
3. 群右上角「**⋯**」→「**群机器人**」→「**添加机器人**」
4. 起个名字（比如 `签到通知`）→ 添加
5. 复制生成的那条 **Webhook 地址**，形如：

   ```
   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=abcdefgh-1234-5678-90ab-cdef12345678
   ```

### 2. 填到控制台

| 字段 | 填什么 |
|---|---|
| 通知方式 | **企业微信群机器人** |
| Webhook 地址 | 粘上一步复制的完整地址 |

点「发送测试通知」→ 群里应该出现一条消息。

## 三、钉钉群机器人 ⚠️ 注意关键词

### 1. 建群 + 加机器人

1. 打开**钉钉** → 建一个群（或用自己的群）
2. 群右上角「**⋯**」→「**智能群助手**」→「**添加机器人**」
3. 选「**自定义**（通过 Webhook 接入自定义服务）」→ 添加
4. **安全设置这一步必须选一个**：

   | 选什么 | 怎么填 |
   |---|---|
   | ✅ **自定义关键词**（推荐） | 关键词填 **`WorkBuddy`** —— 一个字都不能差，大小写敏感 |
   | IP 地址段 | 填你服务器的公网 IP |

   🚨 **不要选「加签」** —— 本工具不支持加签，选了会一直发不出去。

5. 复制 **Webhook 地址**，形如：

   ```
   https://oapi.dingtalk.com/robot/send?access_token=abcdef123456...
   ```

### 2. 填到控制台

| 字段 | 填什么 |
|---|---|
| 通知方式 | **钉钉群机器人** |
| Webhook 地址 | 粘上一步的地址 |

点「发送测试通知」。

> **关键词为什么填 `WorkBuddy`**：本工具推送的标题是「WorkBuddy 签到结果…」，天然包含这个词，所以直接就能过钉钉的关键词校验。

### 3. 如果收不到，钉钉会返回错误码

| 错误 | 原因 |
|---|---|
| `310000 keywords not in content` | 关键词没配对。检查是不是填成了 `workbuddy`（小写）或多了空格 |
| `310000 sign not match` | 你选了「加签」。改成「自定义关键词」 |

## 四、飞书群机器人

1. 打开**飞书** → 进入群 → 右上角「**⋯**」→「**设置**」→「**群机器人**」→「**添加机器人**」
2. 选「**自定义机器人**」→ 添加
3. 「安全设置」里**不要勾签名校验**（本工具不支持），要限制的话用「**自定义关键词**」填 `WorkBuddy`
4. 复制 **Webhook 地址**，形如：

   ```
   https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```

5. 控制台里：

| 字段 | 填什么 |
|---|---|
| 通知方式 | **飞书群机器人** |
| Webhook 地址 | 粘上一步的地址 |

---

## 五、自定义 Webhook

给会写代码的人用。本工具会往你填的地址发一个 **POST**，请求体是：

```json
{
  "msgtype": "text",
  "text": {
    "content": "WorkBuddy 签到结果（daily）\n成功 3/3\n✅ 张三：签到成功"
  }
}
```

任何接受这种格式的服务都能接（自建机器人、中转脚本、Node-RED 等）。

---

## 收不到通知？按这个顺序查

| 检查项 | 怎么查 |
|---|---|
| 1. 点「发送测试通知」有反应吗 | 没反应说明 webhook 没保存。先点「保存设置」，再点测试 |
| 2. 控制台密码框下面有没有红字 | 有错误提示就是地址填错了 |
| 3. 服务器能不能访问外网 | 宝塔终端：`curl -I https://qyapi.weixin.qq.com`（换成你的域名） |
| 4. 钉钉是不是选了「加签」 | 改成「自定义关键词」填 `WorkBuddy` |
| 5. Server 酱有没有关注公众号 | 微信搜「Server酱」关注 |
| 6. 看服务器日志 | 宝塔终端：`journalctl -u workbuddy-checkin -n 50 --no-pager`，搜「通知推送失败」 |

## 附：通知长什么样

**仅失败时**（某天有账号失败）：

```
WorkBuddy 签到结果（daily）
成功 2/3
✅ 张三：签到成功
✅ 李四：今日已签到
❌ 王五：凭据已失效，请在控制台重新添加该账号（HTTP 401）
```

**凭据失效会额外单独提醒一次**（标题「WorkBuddy 登录失效」），这样你能第一时间去重新添加。

---

## 一句话总结

- 想推**个人微信** → **Server 酱**，填 SendKey，关注公众号
- 公司用**企业微信/钉钉/飞书** → 群里加机器人，粘 Webhook
- 钉钉记得选「**自定义关键词**」填 `WorkBuddy`
- 推送时机选「**仅失败时**」，平时不打扰
- 配完**一定点一下「发送测试通知」**确认能收到

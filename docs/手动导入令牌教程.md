# 只粘一串令牌（refreshtoken）· 极简版

> **先看这里**：这篇是给「手上只有一串令牌、找不到 `credentials.json` 文件」的人准备的极简兜底。
> 正常情况请直接去看 **[用户教程-上传令牌.md](用户教程-上传令牌.md)** —— 那个是完整图文版，整份文件拖进去就行，不用挑字段。

---

## 一句话

**把令牌粘进去，只粘一串也行。** 服务器自己会认 `accessToken=` / `refreshToken:` / 逗号分隔的 CSV 行，
也认直接从记事本里框选复制出来的整段 JSON。

---

## 第 1 步：从哪儿弄到这串令牌

只有一种简单来源：**命令行版（CLI）登录后自己生成的 `credentials.json`**。
桌面版图形客户端**通常不生成**这个文件（登录信息加密存在自己目录里，导不出来）。

1. Windows 电脑上装过 **命令行版 CodeBuddy CLI**，并且**登录过一次**
2. 按 `Win + R`，输入下面这一行，回车：

   ```
   %USERPROFILE%\.codebuddy\instances
   ```

   > ⚠️ 注意是**反斜杠 `\`**，不是点。粘成 `%USERPROFILE%.codebuddyinstances` 会提示找不到 —— 这是最常见的错。

3. 会打开一个文件夹，里面有一个或多个 `credentials.json`（或 `credentials-xxx.json`）

   > 💡 找不到？**先在地址栏粘 `%USERPROFILE%\.codebuddy`**（不带 `instances`）看里面有没有 `instances` 文件夹；
   > 还是没有就说明这台电脑没有这个文件（桌面版不生成）。两条出路：**直接改用「电脑端登录」**（0 安装）；
   > 或者你有**另一台装过命令行版的电脑**，在那台上把文件内容复制到微信「文件传输助手」，
   > 再在手机浏览器打开 `/join`，粘进「📋 直接粘贴文件内容」。⚠️ 只能用**你自己账号**的文件。
   > 想省事就双击 `tools/find-credentials.bat`，它会自己在常见位置找、找不到再问你要不要全盘搜。
4. **右键 → 打开方式 → 记事本**

打开后大概是这个样子（挤在一行也正常）：

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9....abcdefg",
  "refreshToken": "rt_9f8e7d6c5b4a3210fedcba9876543210",
  "uid": "1234567890"
}
```

5. 找到 **`"refreshToken"`**，把**后面双引号里的那一整串**复制下来

   ```
   rt_9f8e7d6c5b4a3210fedcba9876543210
   ```

   ⚠️ 只复制引号**里面**的内容，不要连 `"refreshToken":` 和引号一起复制。

> **更省事的做法**：别挑了 —— 直接 `Ctrl + A` 全选、`Ctrl + C` 复制，整段粘进去。服务器会自己挑出需要的字段。
> 这就是「上传令牌文件」那条路的全部操作。

---

## 第 2 步：粘进去

**给管理员加账号用：**
1. 控制台 → 右上角「**+ 添加账号**」→ 标签页「**📄 上传令牌文件**」
2. 那个大输入框里把令牌粘进去（或者把文件拖到上面的虚线框里）
3. 点 **「导入」**

**自己给自己加（对方是普通用户）：**
1. 打开管理员给的自助链接 `https://你的域名/join?t=…`
2. 卡片「方式二 · 上传令牌文件」→ 把文件拖进去，或点一下选文件

---

## 第 3 步：确认成功

成功后你会当场看到：

- 绿色的 `导入成功` 提示
- 账号昵称
- **属于这个账号的查看账号 / 密码 / 地址 `/me`** —— 截个图存好

之后服务器会自动换新令牌、自动续期，**你不用再管这串令牌**。

---

## 常见问题

| 你看到的提示 | 原因 | 怎么办 |
|---|---|---|
| 「认不出里面的令牌」 | 粘的不是令牌（比如粘了文件夹地址、文件名、或者别的文字） | 打开 `credentials.json`，`Ctrl + A` 全选再复制 |
| 「内容太大了」 | 把整个目录打包传上来了 | 只传 `credentials*.json` 这一个文件，上限 256 KB |
| 「导入失败：令牌无效」 | 这串令牌在官方客户端那边已经过期了 | 打开官方客户端重新登录一次，再复制新的 |
| 导入成功但状态是「需重新登录」 | 同上，令牌已废 | 重新登录客户端后重新导入一次，会按 uid 覆盖，不用先删 |
| 找不到 `instances` 文件夹 | 只装了桌面版，或 CLI 没登录过 | 桌面版不会有；改用「电脑端登录」，或从另一台装过 CLI 的电脑搬内容过来 |
| 完全不想弄令牌 | —— | 用「🖥 电脑端登录」，手机扫电脑屏幕就行 |

---

## 一句话总结

**整份 `credentials.json` 全选复制 → 粘进去 → 完事。**
不用分辨哪个是 accessToken、哪个是 refreshToken，也不用管 uid 和域名 —— 服务器全都自己认。

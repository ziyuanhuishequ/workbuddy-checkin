# 更新说明 v1.5.3

> 修积分对不上：**官网 2,865.53，工具里显示 2,866 / 2865**。
> 这一版让「官方页面 / 控制台 / 用户自助页 / 微信推送」四个地方显示同一个数。

---

## 为什么会差 0.47

官方余额是带小数的（`2,865.53`），工具里三处各自把小数点吃掉了：

| 位置 | 老代码 | 结果 |
|---|---|---|
| 微信推送 | `_fmt_num()` 里 `int(round(float(v)))` | `2,866` ❌ |
| 控制台「可用积分」合计 | `db.credits_total()` 里 `int(row["c"])` | `2,865` ❌ |
| 前端表格 / 自助页 | 直接拼数字，没有千分位 | `2865.53`（数值对，样式和官网不一样） |

所以：**数据本身是准的（`wb.query_balance()` 会把各资源包剩余额度按 float 相加），
坏在“最后一步显示”把它改掉了。**

---

## 改了什么

### 1. 格式化一律保留真实精度

```python
def _fmt_num(value):
    num = float(value)
    if abs(num - round(num)) < 1e-6:      # 整数就显示整数
        return f"{int(round(num)):,}"
    return f"{num:,.2f}"                  # 带小数就保留两位
```

- `2865.53` → **`2,865.53`**
- `1100` → `1,100`（不会变成 `1,100.00`）

### 2. 后台合计不再 `int()` 截断

`db.credits_total()` 现在返回 `round(float(...), 2)`，
`db.today_credit()` 同理 —— 否则「各账号加起来」和「总积分卡」永远差几分钱。

### 3. 每日推送带上**实时余额**

以前每日签到推送只有一句「本次获得 100 积分」，没有余额；要看余额得自己去官网。
现在推送是这样的：

```
账号「xxx」签到成功
本次获得 100 积分

📊 当前积分余额：2,865.53（官方实时值）
查看积分：https://wb.example.com/me
```

标题也带上了：`✅ 今日已签到｜余额 2,865.53`

余额用的是**签到那一刻刚查到的值**（`wb.query_status()` 的返回），
不是数据库里的旧数字，所以和官网同一秒对得上。

### 4. 控制台标注「截至什么时候」

积分只在「签到 / 自检 / 登录」时从官方拉一次（不然每次刷新页面都打上游接口）。
所以卡片下面加了一行小字：

> 官方数据，截至 10-29 18:40　点右上「全部自检」刷新

这样你看到旧数字时，知道是**没刷新**，而不是**算错了**。

### 5. 前端统一格式

控制台、账号表格、用户自助页都加了 `fmtNum()`：
整数 → `2,866`，带小数 → `2,865.53`，和官网一个样式。

## 改了哪些文件

| 文件 | 改动 |
|---|---|
| `app/service.py` | `_fmt_num` 保留小数；`notify_account_result` 增加实时余额；`overview` 带 `credits_updated_at` |
| `app/db.py` | `credits_total()` / `today_credit()` 不再 `int()` 截断 |
| `app/static/index.html` | 新增 `fmtNum()`，积分/合计/今日获得统一格式化；积分卡加「截至」 |
| `app/static/portal.html` | 同样接入 `fmtNum()` |
| `app/config.py`、`app/__init__.py` | `VERSION` → `1.5.3` |

数据库不用迁移：SQLite 的 `INTEGER` 列存不下的 `2865.53` 会自动按 REAL 存，
所以老库里的值本来就是准的，只是显示被截了。

## 升级方法（必须重启）

1. 上传覆盖（保持目录结构，别套成 `app/app/`）：

```
app/service.py
app/db.py
app/main.py
app/config.py
app/__init__.py
app/static/index.html
app/static/portal.html
```

2. 重启服务（见下面「重启」）
3. 打开 `https://wb.example.com/api/health` → 必须显示 `"version":"1.5.3"`

### 重启

宝塔「网站 → Python 项目」里如果没有这个项目，说明是 systemd 服务（`deploy/install-bt.sh` 装的）。
在宝塔「终端」里：

```bash
systemctl restart workbuddy-checkin
```

不确定是哪种？先跑这行看看：

```bash
systemctl is-active workbuddy-checkin; ps -ef|grep run.py|grep -v grep
```

1. 控制台点右上 **「全部自检」**（会把每个账号的官方余额重新拉一遍）
2. 对照「可用积分」当前值和官网 `2,865.53`

如果三者都一致 → 收工。

## 顺带说明

`积分总额`（`credits_total`，各资源包**原始总量**）和 `可用积分`（`credits`，**当前剩余**）
是两个不同的数，官网页面上显示的是「积分余额」= 可用积分。
如果你看到 `/ 5,000` 这种，那是「剩余 / 总量」，不是两个不同的余额。

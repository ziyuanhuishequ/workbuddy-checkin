# v1.3.0 更新说明：一键清理失效账号 + 扫码登录不再卡住

> 一句话：**账号列表里「需重新登录」的那些僵尸号，现在一个按钮就能清干净（也能设成自动清）；
> 扫码登录也改了引导 —— 微信扫不上的，用手机相机扫就行。**

## 一、一键清理失效账号（新增）

### 在哪儿

控制台 →「账号」标签 → 表格上方会出现一行：

```
有 3 个账号需重新登录        [🧹 清理失效账号]
```

这行**只在真有失效账号时才显示**，账号全正常的时候它是藏起来的，不会碍事。

### 怎么用

1. 点「🧹 清理失效账号」
2. 弹窗里选清理范围：
   - **全部失效账号** —— 一个不留
   - **失效超过 7 天的**
   - **失效超过 30 天的**
3. 弹窗会实时统计：「将清理 **3** 个账号：张三、李四、王五」
4. 点「确认清理」→ 再确认一次 → 完成

> ⚠️ 只删除**本服务器上保存的登录凭据**，你的 WorkBuddy 账号本身完全不受影响，
> 以后重新扫码还能加回来。所以清掉不可惜。

### 顺带的好处

清理时会在日志里留一条记录：

```
[cleanup] 清理失效账号 3 个（全部失效账号）：张三、李四、王五
```

以后想知道「谁什么时候被我删了」，翻日志就有。

## 二、按天自动清理（新增，可选）

如果你懒得手动点，可以让它自己清。

**位置**：控制台 →「设置」→「签到」卡片 → 最后一项

```
自动清理失效账号（失效满 N 天自动删除，0 = 关闭）  [ 0 ]
```

| 填什么 | 效果 |
|---|---|
| `0` | 关闭（默认，不会自动删任何东西） |
| `7` | 账号失效满 7 天后，自动删除 |
| `30` | 账号失效满 30 天后，自动删除 |

**说明几点**：

- 每天只跑一次，不会反复扫描
- 计时起点是「账号被判定失效的时间」，不是「添加账号的时间」
- 只清 `需重新登录` 状态的账号，状态正常的**绝对不会被动**
- 自动清理同样会写日志：`[cleanup] 自动清理失效账号 2 个（失效超过 7 天）`

> 建议：**先留 0**，用一段时间手动清。等确认失效账号确实都是不要的了，再设成 30 天。

## 三、扫码登录：改引导，不再让你在微信里反复失败

### 原来的坑

用微信「扫一扫」扫二维码 → 微信内置浏览器打开登录页 → 提示「登录失败 / 请返回客户端重新发起」。

这不是软件的 bug，是**微信内置浏览器**和上游登录页（OneID / 微信 OAuth）合不来。
同样的链接换成手机自带浏览器打开，一次就成。

### 现在的界面

**A. 二维码下面直接写了正确姿势**

```
请用手机「相机」扫码，不要用微信「扫一扫」
微信内置浏览器经常提示「登录失败」，用相机 / 手机浏览器扫就不会
```

**B. 多了一个「📱 复制登录链接」按钮**

二维码出来之后，这个按钮就会出现。点了它：

- 链接进剪贴板
- 发给自己（微信「文件传输助手」最方便）
- 在手机上**点链接 → 选「用浏览器打开」**
- 浏览器里正常登录，服务器这边会自动收到账号，不用回来点任何东西

**C. 扫失败了会自动提示你怎么办**

如果轮询了 1 分半还没成功，或者上游返回失败，界面会自动弹出一段话：

```
扫码后手机提示「登录失败 / 请返回客户端重新发起」？
说明是微信内置浏览器的问题：点上面的 复制登录链接，发到手机 浏览器 里打开就能登录成功。
```

## 四、手动导入令牌：界面简化 + 配了篇教程

### 界面变了

「手动导入令牌」标签页顶部现在有一句话，直接告诉你**只填一格就行**：

```
只需要填第一格（refreshToken），其余全部留空，点「导入」就行。
填了 refreshToken 之后，服务器会自己换新的 accessToken 并一直帮你续期，以后不用再扫码。
```

下面还收了一个可折叠的 **「❓ refreshToken 从哪儿来？（点开看）」**，里面写了三种情况，
其中最好用的是第二种：从你电脑上的官方客户端凭据文件里复制。

### 新文件：`手动导入令牌教程.md`

项目根目录新增这份教程，**零基础能照着做**，内容包括：

- 第 0 步：先别折腾令牌，用手机相机扫码（30 秒搞定）
- 第 1 步：`Win + R` 输入 `%USERPROFILE%\.codebuddy\instances`，记事本打开 `credentials.json`，
  复制 `"refreshToken"` 引号里那一串
- 第 2 步：只粘第一个格子，其余留空
- 第 3 步：怎么确认导入成功
- 一张「报错对照表」：`无效的令牌` / `缺少 refreshToken` / `导入成功但状态是需重新登录` 分别怎么办

## 五、升级方法（照旧，不用重装）

### 宝塔用户

1. 宝塔 →「文件」→ 进到项目目录（比如 `/www/wwwroot/workbuddy-checkin`）
2. **先备份**：把 `data/` 整个文件夹复制一份到别处（里面有账号和密码，别丢）
3. 上传 `workbuddy-checkin-1.3.0.zip` → 右键「解压」→ 覆盖
   > 注意：**不要**覆盖 `data/` 目录，账号数据都在里面
4. 宝塔 →「网站」→ 找到你的站点 →「Python 项目」→ 点「重启」
5. 打开控制台，右上角版本应显示 **1.3.0**

### 命令行用户

```bash
cd /www/wwwroot/workbuddy-checkin
cp -r data data.bak.$(date +%Y%m%d)     # 备份
unzip -o ~/workbuddy-checkin-1.3.0.zip -d .
systemctl restart workbuddy-checkin      # 或 supervisorctl restart workbuddy-checkin
```

### 验证升级成功

| 检查点 | 期望 |
|---|---|
| 控制台右上角版本 | `1.3.0` |
| 「账号」页有失效账号时 | 出现「🧹 清理失效账号」按钮 |
| 「设置 → 签到」最后一项 | 有「自动清理失效账号」输入框 |
| 「添加账号 → 扫码登录」 | 二维码下方写「请用手机相机扫码」+ 出现「复制登录链接」按钮 |

## 六、兼容性

- **数据库结构没变**，直接从 1.1.x / 1.2.0 覆盖升级即可，不用迁移
- 新增的 `auto_cleanup_days` 配置项默认值 `0`，**升级后不会自动删任何账号**
- 老版本没有这个配置项也没关系，读不到时按 0 处理

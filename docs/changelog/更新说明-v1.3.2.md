# v1.3.2 修复说明：登录链接只能用一次（这就是「登录失败」的原因）

> 一句话：**那个「登录失败 / 请返回客户端点击「重新发起登录」重试」的页面，99% 是因为你在反复点同一条链接 ——
> 官方给每条链接配的 `state` 只能用一次，用掉/过期后再打开就永远是这个错。**
> 现在每次点「复制登录链接」都会**重新申请一条全新的**，不会再让你拿着一条死链反复试。

---

## 一、这个页面到底是什么

截图里那个橙色的 **「！ 登录失败 / 请返回客户端点击「重新发起登录」重试 / 问题标识：xxxx」** 页面，
是**官方登录页自己的回调结果页**，跟本工具有没有登录成功没关系。

官方前端代码里这条文案是这么来的（抓包反编译得到，原样摘录）：

```js
const S = "请返回客户端点击「重新发起登录」重试";
class LoginCallbackError extends Error { ... }   // 回调换 token 失败时抛这个
// 结果页：
fail: { icon: 橙色感叹号, text: "登录失败", desc: S }
o === "fail" && requestId && <div>问题标识：{requestId}</div>
```

也就是说：**浏览器带着 `code` 回到官方页面，官方拿这个 `code` 去换登录票据，换失败了** —— 于是给你这句通用提示，
外加一个 `问题标识`（就是一个请求 id，专门给客服排查用的，对你没有别的用处）。

换失败只有两个常见原因：

| 原因 | 表现 | 怎么办 |
|---|---|---|
| **① 链接被用过了 / 过期了**<br>（`state` 一次性） | 打开就直接是这个页面，连二维码都看不到 | 重新生成一条新链接（v1.3.2 已自动做） |
| **② 在微信内置浏览器里打开** | 同上，或扫完立刻失败 | 改成在**电脑浏览器**打开 |

> 你之前一直在点 `https://copilot.tencent.com/login?platform=CLI&state=49b2f466-...` **同一条地址** ——
> 那条 `state` 第一次打开就消耗掉了，后面再怎么点都是「登录失败」。换新链接就好了。

## 二、v1.3.2 改了什么

| 改动 | 位置 | 说明 |
|---|---|---|
| 复制链接前**重新申请 state** | `static/index.html` | 点「📋 复制登录链接」时先申请一条新的，再复制新链接（不再复用屏幕上那条） |
| 「在本机浏览器打开」同样换新链接 | 同上 | 每次点都是一个全新的 `state` |
| **同时盯多条链接** | 同上 | 轮询列表化：之前发出去的几条链接，任意一条扫成功都能立刻识别，不会「你扫的是旧码、我只盯新码」 |
| 失效链接自动摘除 | 同上 | 某条被用掉/过期就从轮询里移除；全部失效才提示「二维码已失效」 |
| `/join` 自助页同步 | `static/join.html` | 「复制登录链接」按钮每次点击都会重新取一条新链接 |
| 文案补上「每条链接只能用一次」 | 两个页面 | 看到「登录失败」就知道该点哪里换新的，不用猜 |

## 三、正确的操作顺序（照着做，一次就成）

1. 控制台 →「+ 添加账号」→ 等二维码出来
2. 点「📋 **复制登录链接**」（这一步会给一条全新的）
3. 把链接发到**电脑**（微信发给自己 / QQ / 记事本都行），用**电脑浏览器**（Chrome、Edge）打开
4. 电脑屏幕上会出现一个**二维码** —— 看到二维码就说明链接是好的
5. 手机用**微信**扫电脑屏幕上这个码 → 手机上点「确认登录」
6. 控制台弹窗自动变成 ✅（不用回电脑点任何东西，服务器自己在轮询）

**判断标准：**
- 电脑上看到**二维码** → 正常，继续第 5 步
- 电脑上直接看到**「登录失败」** → 这条链接已经废了，回第 2 步重新复制一条（一键就换新，不用关弹窗）

## 四、升级方法

> ⚠️ 版本号必须变成 **1.3.2** 才算新文件生效。还是 1.3.1 / 1.3.0 说明文件没覆盖上、或者服务没重启。

### 宝塔

1. 备份 `data/` 整个目录
2. 上传 `workbuddy-checkin-1.3.2.zip` → 解压覆盖（**不要覆盖 `data/`**）
3. 重启：网站 →「Python项目」→ 项目行右侧「重启」；没有这个菜单就用「终端」执行 `systemctl restart workbuddy-checkin`
4. 浏览器 Ctrl+F5 强刷 → 右上角显示 **1.3.2**

### 命令行

```bash
cd /www/wwwroot/workbuddy-checkin
cp -r data data.bak.$(date +%Y%m%d)
unzip -o ~/workbuddy-checkin-1.3.2.zip -d .
systemctl restart workbuddy-checkin
```

## 五、兼容性

- 只改了前端页面 + 版本号，**后端接口一个没动**，数据库不用迁移
- 老账号、签到记录、清理设置全部不受影响
- 如果你现在还是 1.3.1，只想要这条修复，也可以**只替换** `app/static/index.html` 和 `app/static/join.html` 两个文件后强刷（不用重启服务）

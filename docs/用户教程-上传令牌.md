# 用户教程：怎么把自己的账号加进来（上传令牌文件）

> 这份教程是给**完全不懂电脑的人**看的。照着一步一步做就行，**不用改任何代码、不用记命令**。
>   
> 全程大约 **3 分钟**。做一次，以后就不用再弄了（服务器会自动帮你续期、每天自动签到）。

---

## 先说清楚：这份教程只适合一种人

**只有「电脑上确实有 `credentials.json` 这个文件」的人，才需要看这份教程。**

做法很简单：把这个文件上传到我们给你的那个网页里。上传完，网页会给你一组「查看账号 + 查看密码」，
凭这组账号密码就能随时看自己的积分和签到情况。

> ⚠️ **但先说一句实话，能省你半小时**：这个文件**绝大多数人电脑上都没有**。
>
> 它是「命令行版（CLI）」登录后才生成的。只装了**桌面版 App**、或者只用**网页版**的人，
> 电脑里**根本没有它** —— **不是你不会找，是它不存在**，任何工具都变不出来。
>
> **不确定自己装的是哪种？** 那就**别往下看了**，直接用另一个办法（0 安装、人人可用）：
> 打开给你的链接 → 点「**🖥 打开电脑端登录页**」→ 手机扫电脑屏幕 → 完事。
>
> **确定自己装过命令行版？** 再往下做，第 1 步就是帮你确认，30 秒出结果，全程 3 分钟。

---

## 第 0 步：确认你在哪台设备上

| 你现在用的                   | 能不能做                           |
| ----------------------- | ------------------------------ |
| **Windows 电脑 / Mac 电脑** | ✅ 能，全程都能做（推荐）                  |
| **手机**                  | ⚠️ 这一种办法需要电脑上的文件，所以**请先到电脑上做** |

> 手机上打开我们的链接，页面会提示「这一步需要电脑」，那是正常的。



---

## 第 1 步：找出 `credentials.json`（四选一，从上面往下试）

### 方法 A（最快）：双击小工具，它自己找

管理员可能会发给你一个叫 **`find-credentials.bat`** 的文件。

1. 把它下载到桌面
2. **双击它**
3. 窗口里会出现黑底白字，看到「**找到**」就是有了；看到「**这台电脑上没有**」就是没有

有的话它会问你两件事：

- 要不要把内容**复制到剪贴板** → 输 `Y` 回车（这样等下在网页里 `Ctrl+V` 就能粘）
- 然后自动帮你**打开文件所在的文件夹**

> ⚠️ 双击时如果弹出「Windows 已保护你的电脑」，点「**更多信息**」→「**仍要运行**」。
>   
> 这是所有从网上下载的 .bat 都会有的提示，不是病毒。

### 方法 B：不装任何东西，粘一行路径（10 秒）

1. 按 **`Win` + `R`**（`Win` 是键盘左下角那个窗口图标）
2. 小输入框里粘这一行：

```
%USERPROFILE%\.codebuddy\instances
```

1. 按 **回车**
2. 如果弹出了文件夹 → ✅ 有了，里面有 `credentials.json`
     
   如果弹出「找不到」的错误框 → ❌ 没有，跳到方法 C 再确认一次

> ⚠️ **九成人失败都是同一个原因**：这行里是**反斜杠 `\`**（回车键上方那个），不是点 `.`，也不是斜杠 `/`。
>   
> 粘成 `%USERPROFILE%.codebuddyinstances` 一定找不到。粘贴前先看一眼有没有 `\`。

### 方法 C：窗口自带的搜索（万能，慢一点）

前面两条都是在「固定位置」找。如果你的客户端装在别的地方，用这个：

1. 按 **`Win` + `E`** 打开「文件资源管理器」
2. 左边点「**此电脑**」
3. 点**右上角的搜索框**，输入：

```
credentials.json
```

1. 按回车，**等它搜完**（1～3 分钟，进度条在走就是正常的）
2. 出现结果就说明有；搜索框下面显示「没有找到」就是真没有

### 方法 D：Mac 电脑

1. 按 `Command` + 空格，输入「**终端**」，回车
2. 粘这一行，回车：

```
mdfind -name credentials.json
```

1. 有结果 → 记下路径；什么都没打印 → 没有这个文件

> Mac 上 `.codebuddy` 是隐藏文件夹，用「前往文件夹」输 `~/.codebuddy/instances` 也能直接进。

---

### 结果对照表

| 你看到的                                            | 说明        | 下一步                    |
| ----------------------------------------------- | --------- | ---------------------- |
| 找到 `credentials.json`（或 `credentials-xxx.json`） | ✅ 你有      | 继续第 2 步                |
| `instances` 文件夹是空的                              | ❌ 装过但没登录过 | 走「[确实没有怎么办](#确实没有怎么办)」 |
| 四种方法都说找不到                                       | ❌ 这台电脑没有  | 走「[确实没有怎么办](#确实没有怎么办)」 |

> 文件名可能是 `credentials.json`，也可能是 `credentials-1a2b.json` 这种带后缀的，
>   
> 有的电脑还不显示 `.json`、只显示 `credentials` 加个图标 —— **都算**。

## 第 2 步：上传上去

1. 电脑浏览器打开管理员给你的**那个链接**（`https://你的域名/join?t=…`，很长那串，别改它）
2. 页面往下拉，找到「**方式二：上传令牌文件（不想用电脑就选这个）**」这一块
3. **两种上传方式，选一种**：

   **方法 ①（最简单）**：用鼠标按住那个 `credentials.json` 文件，**直接拖到**网页的虚线框里，松手。

   **方法 ②**：点虚线框里的「**点这里选择文件**」→ 在弹出的窗口里找到它 → 双击。

   **方法 ③**：如果刚才用小工具复制到了剪贴板，直接点虚线框**下面的输入框**，按 `Ctrl + V` 粘进去，再点「导入」。
4. 页面显示「**正在解析并导入，请稍等…**」，一般 2～5 秒。

**你会看到什么：**

- ✅ 成功 → 页面跳到「**你的专属查看账号**」，有账号、密码、查看地址
- ❌ 失败 → 页面弹一条红色提示，写着原因，对照下面「常见问题」处理

---

## 第 3 步：把账号密码存好（重要）

成功后会显示「**你的专属查看账号**」，下面是三行：

```
账号：  user1234
密码：  ab12cd34ef
查看地址： https://你的域名/me
```

- 点「**复制账号密码和地址**」，粘到微信「文件传输助手」发给自己，或者截图存起来
- 以后想看积分/签到情况：浏览器打开「查看地址」，用这组账号密码登录
- **存好它**。忘了不用慌：找管理员，他在后台能看到这组账号密码发给你，也可以给你重置一个新的

## 确实没有怎么办

**不用再找了** —— 这个文件是 `@tencent-ai/codebuddy-code` 这个**命令行版**登录后自己生成的。
  
只装桌面版 App、或者只用网页版的人，电脑里从来不会有它。**任何工具都变不出来**，接受这一点，然后从下面三条里选一条：

### 路线 1（推荐，0 安装）：用「电脑端登录」

完全不需要文件，人人可用：

1. 电脑浏览器打开管理员给你的那个链接（`.../join?t=...`）
2. 点「**🖥 打开电脑端登录页**」→ 会新开一个标签页，里面是官方登录页
3. **手机微信扫电脑屏幕上那个二维码** → 手机上点「确认登录」
4. 页面自动变成 ✅，同样会给你「查看账号 / 密码 / 地址」

> ⚠️ 一定要**在电脑上**开这个页面。在手机微信里直接点链接是登不上的（微信内置浏览器会被官方页面拦下来），
>   
> 页面上如果只显示「复制本页链接，发到电脑打开」，就照它说的做。

### 路线 2（你还有另一台电脑）：把内容搬过来

很多人是**公司那台电脑装过命令行版、家里这台没装**。这种情况不用重装，把内容搬过来就行：

1. 回到**公司那台**电脑，按第 2 步的方法找到 `credentials*.json`
2. **右键 → 打开方式 → 记事本**（别双击，双击可能打不开）
3. 按 `Ctrl + A` 全选，再按 `Ctrl + C` 复制
4. 打开微信 →「**文件传输助手**」→ 把内容粘进去，发给自己
5. 手机微信打开这条消息 → 长按 → 全选 → 复制
6. 手机浏览器打开链接（**别在微信里直接开**，点右上角「…」→「在浏览器打开」），
   展开「**📋 或者直接粘贴文件内容**」，粘进去 → 点「导入这段内容」

> ⚠️ **只能用你自己账号的文件**。拿同事的文件来导，签到的是同事的账号，你自己的还是没签 ——
> 这个文件里装的就是「谁的登录凭证」，不存在"借用"。

### 路线 3：如果你本来就会用命令行，可以自己造出这个文件

> 给「电脑上已经装过 Node.js、会用命令行」的人。小白**别碰这条路**，直接用路线 1。

1. 装命令行版（需要 Node.js 18.20 以上）：
   ```
   npm install -g @tencent-ai/codebuddy-code
   ```
   装不上就用国内镜像：
   ```
   npm install -g @tencent-ai/codebuddy-code --registry https://registry.npmmirror.com
   ```
2. 在任意目录跑：
   ```
   codebuddy
   ```
3. 按提示选「**Log in via Chinese Site**」→ 会自动打开浏览器 → 用你的账号登录完成
4. 登录成功后，文件就出现在 `%USERPROFILE%\.codebuddy\instances\` 里了
5. 回到第 2 步上传

> 装完登录了、`instances` 里还是空的？说明这个版本不落盘这个文件，**别再折腾**——
> 卸载了也不影响什么，直接回路线 1，那条路永远有效。

## 常见问题

### 1）粘路径回车，提示「找不到路径」

先查**反斜杠**：正确写法是 `%USERPROFILE%\.codebuddy\instances`，中间的 `\` 一个都不能少。
  
粘成 `%USERPROFILE%.codebuddyinstances` 必然找不到 —— 这是最常见的原因。

反斜杠没错还是找不到 → 这台电脑确实没有，看上面「[确实没有怎么办](#确实没有怎么办)」。

### 2）文件找到了，但打开看里面没有 `refreshToken`

老版本可能只有 `token` 字段。**不影响**：整个文件原样上传，服务器会认 `token`（accessToken）。
  
只是这种令牌会过期，过期后需要再传一次。

### 3）上传后提示「没能从内容里找到 accessToken / refreshToken」

说明传错文件了。常见的错：

- 传了客户端的**安装包**（`.exe` / `.dmg`）→ 不是它
- 传了**日志文件**（`.log`）→ 不是它
- 传了个**空文件夹或快捷方式** → 不是它

要的是名字以 `credentials` 开头、`.json` 结尾的那个文件。

### 4）页面提示「链接无效或已失效，请向管理员索取最新链接」

管理员换过链接了（旧链接立刻作废）。找他要一条**新的完整链接**，从头再来。

### 5）页面提示「文件太大：只需要 credentials*.json 这个文件本身」

你传的不是凭据文件。`credentials.json` 一般只有几 KB，超过 256KB 就一定不是它
  
（常见误传：安装包、日志、整个文件夹打的压缩包）。

### 6）我只有手机，没有电脑

两条路都需要一台电脑。可以找身边人借一台电脑，或者让管理员当面帮你处理一次 —— **加进来之后就不用再碰电脑了**。
  
（加好之后，手机上用浏览器打开 `/me` 就能看积分，不需要电脑。）

### 7）上传成功之后，以后还需要再上传吗？

**不需要。** 服务器会拿你给的 refreshToken 自动续期、每天自动签到。只有这两种情况才需要重来一次：

- 你在客户端里点了「退出登录」或者改了密码（令牌失效）
- 很久没用（几个月），refreshToken 也过期了

### 8）双击 `find-credentials.bat` 被 Windows 拦住了

点「**更多信息**」→「**仍要运行**」。从网上下载的 .bat 都会触发这个提示，是系统对所有脚本的通用拦截。
  
如果你还是不放心，用方法 B（粘路径）或方法 C（此电脑搜索），效果一样。

## 两句安全提醒

1. 这个文件 = 你的登录凭据，**当成密码看待**。不要发到群里、不要发给陌生人、不要传到网盘。
2. 我们只在你上传的那一刻读一次，之后加密存在服务器本地，**不会发给任何第三方**。
     
   你随时可以在 `/me` 页面里点「退出登录」，服务器会立刻删掉你的全部凭据。

## 一句话原理（不爱看可跳过）

- **为什么手机微信直接扫码登不上**：官方登录页里有一段脚本专做「微信内网员工探测」，识别到微信浏览器就把人踢去做内部授权，
    
  普通用户过不去，最后就是「登录失败」。所以必须**在电脑浏览器里打开**，让电脑屏幕出现二维码，再用手机扫那个码。
- **为什么这个文件不是人人都有**：它是**命令行版**（`@tencent-ai/codebuddy-code`）登录后写的，
    
  桌面版 App 的登录信息是加密存在自己目录里的，导不出来 —— 所以桌面版用户只能走「电脑端登录」。

## 附：给管理员的话（用户看不到这段也没关系）

- 本教程对应的两条路：**电脑端登录**（人人可用）、**上传令牌文件**（只有 CLI 用户有文件）
- 想让大家都能用「上传」这条路，只能让用户先装 CLI 登录一次，成本较高；
    
  实际推荐直接把 `/join` 链接发出去，让人**默认用电脑端登录**
- `find-credentials.bat` 在项目 `tools/` 目录下，可以直接发给用户；它只做两件事：
    
  在常见位置找 `credentials*.json`、找不到时按 Y 全盘再搜一次，找到后可一键复制内容到剪贴板

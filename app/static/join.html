方式一：在电脑上登录（推荐 · 绝大多数人用这个）
点下面的按钮，会新开一个登录页
四步：
① 在电脑上点「打开电脑端登录页」（会弹出新标签页）
② 那个页面里会出现一个二维码
③ 手机用微信扫电脑屏幕上的二维码，手机上点「确认登录」
④ 这个页面会自动变成 ✅
🖥 打开电脑端登录页
⚠️ 这条链接只能在电脑浏览器里打开。发到微信里、或在手机浏览器里打开，都会提示「登录失败」—— 那是微信内置浏览器打不开官方登录页，不是链接失效。

方式二：上传令牌文件（少数人用，你得先确认有这个文件）
⚠️ 先说清楚：大概率你电脑上没有这个文件，别白找。
这个文件只有装了 「命令行版」 并且登录过一次才会自动生成。 只装了 桌面版 App、或者只用网页版 / 手机的人，电脑里根本没有它 —— 不是你不会找，是它不存在，任何工具都变不出来。
凡是不确定自己装的是哪种的，直接用上面的「方式一」，别在这里耗时间。
✅ 我确定自己装的是命令行版，怎么找？点这里
把你电脑上官方客户端的凭据文件传上来，服务器会自己解析，你不用挑字段。
文件名是 credentials*.json，通常在下面这个位置。
Windows：按 Win + R，粘下面这行，回车 ——
%USERPROFILE%\.codebuddy\instances
⚠️ 里面是反斜杠 \，不是点 .。粘成 %USERPROFILE%.codebuddyinstances 一定提示找不到（九成人栽在这）。

不记得装哪儿了：Win + E 打开「此电脑」→ 点右上角搜索框 → 输入 credentials.json → 回车，等 1～3 分钟。

Mac：打开「终端」，粘 mdfind -name credentials.json 回车。

一条都没搜到？那就是上面说的「你装的是桌面版」， 别再折腾了 —— 点「🖥 好，我用方式一」。
实在想继续用这种方式，只有两个办法：
① 你还有另一台电脑（公司那台装过命令行版）→ 在那台上把文件内容用记事本 Ctrl + A 全选、Ctrl + C 复制 → 发到微信「文件传输助手」→ 粘进下面那个「📋 直接粘贴文件内容」；
② 自己在电脑上装命令行版（需要 Node.js，会用命令的人才试）。

⚠️ 只能用你自己账号的文件。拿同事的文件来导， 签到的是同事的账号，你自己的还是没签。
📋 或者直接粘贴文件内容
把 credentials.json 用记事本打开 → Ctrl + A 全选 → Ctrl + C 复制 → 粘到下面，点「导入」。
